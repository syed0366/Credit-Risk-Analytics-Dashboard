# Credit Risk & Financial Analytics Dashboard

## Project Overview

This Power BI project analyzes customer credit profiles, debt exposure, loan behavior, payment delays, and income patterns to support financial risk assessment and business decision-making.

## Tools Used

* Power BI
* DAX
* Power Query
* Microsoft Excel

## Dashboard Pages

### Overview Dashboard

* Credit Score Distribution
* Credit Mix Analysis
* Income Analysis
* Payment Delay Impact

### Risk Analysis Dashboard

* Outstanding Debt Analysis
* Credit Utilization Trends
* Delayed Payment Analysis
* Customer Risk Segmentation

### Loan Insights Dashboard

* Loan Distribution Analysis
* Credit Inquiry Analysis
* EMI Analysis
* Monthly Salary Analysis

## Key Business Insights

* Poor credit customers contribute the highest outstanding debt.
* Delayed payments significantly increase interest rates.
* Good credit customers represent the largest customer segment.
* Credit utilization trends help identify potential financial risks.
